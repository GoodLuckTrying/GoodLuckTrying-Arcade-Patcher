GoodLuckTrying's Hacks

Browser-based Arcade ROM patchers.

Tip: Previews work from file://, but the patcher needs HTTP. Double-click serve.bat or run python -m http.server 8080 and open http://localhost:8080/ to patch ROMs.

Legal: You must own a legitimate copy of the original arcade ROMs to use these patches. These tools are for owners who wish to apply fan-made modifications to ROMs they already possess. No copyrighted game ROMs are distributed here — only patch data.
