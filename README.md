# GoodLuckTrying/Wolfric's Hacks

Browser-based ROM patchers for arcade hacks by [GoodLuckTrying](https://github.com/GoodLuckTrying). Pick a hack, upload your **stock** MAME/FBNeo romset `.zip`, and download a patched romset — all in your browser. **Your files never leave your device.**

Access the Page here: https://goodlucktrying.github.io/GoodLuckTrying-Arcade-Patcher/

## Before you start

- You must **own a legitimate copy** of the original arcade ROMs. This site provides patch data only, not game ROMs.
- You need the correct **base romset** for the hack and region you want (for example `gng.zip` for Ghosts'n Goblins, `ghouls.zip` for Ghouls'n Ghosts).

## How to patch

1. Open the site and choose a hack.
2. **Upload** your stock romset `.zip`.
3. Wait for **verification** — the site checks that your files match a supported base set.
4. **Choose** the patch you want (region and variant, when several are available).
5. Click **Patch & download** to save the patched `.zip`.

Each hack page also links to a **YouTube trailer**, a **full release download**, and **boxart(s)** (where available).
